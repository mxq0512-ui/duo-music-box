# DUO MUSIC BOX

复古机械八音盒 iPhone App（SwiftUI 原生实现，独立开发线）。

一台可以在 iPhone 上开盒、上发条、装音钉编曲并播放的数字机械八音盒：胡桃木盒盖在上，黄铜滚筒、音梳、齿轮与发条在下；同一份旋律数据同时驱动声音、机械动画、编辑器与本地保存。音色全部由程序合成（基频 + 非谐泛音 + 指数衰减），不使用任何外部素材，零第三方依赖。

## Phase 1 内容

- Xcode 工程（iOS 17+，Swift 5）：`DuoMusicBox.xcodeproj`
- 主界面：开盒动画、上半盒盖 / 下半机械主体的统一结构
- 播放引擎：以音频时钟步进为单一事实来源，前视调度，滚筒角度由纯逻辑推导
- 音钉编辑器：8 音高 × 16 步，点按增删音钉，即时改变旋律
- 发条模型：储能影响转速，耗尽停转，上链恢复
- 本地保存：旋律与礼物草稿 JSON 落盘
- 单元测试：`DuoMusicBoxTests`（旋律编解码、编辑逻辑、步进/角度推导、礼物往返）

## 构建

用 Xcode 打开 `DuoMusicBox.xcodeproj`，选择 iPhone 模拟器运行；或等待 GitHub Actions 的云端 Mac 构建结果（`.github/workflows/ios-build.yml`，推送到 main 自动触发构建与测试）。

## 说明

本仓库为私有项目仓库。数字礼物的线上分享服务不在 Phase 1 范围内（仅含数据模型与草稿表单），计划在后续 Phase 实现。
